# Etapa 05
Execute npm install e npm run dev. A configuração pública do Supabase está em .env.local (também em .env.example). Configure Site URL http://localhost:5173 e Redirect URLs http://localhost:5173/feed e http://localhost:5173/nova-senha no painel Authentication > URL Configuration. Configure SMTP próprio para testes com destinatários externos, conforme limites do Supabase. O cadastro de artista registra intenção; depois do login, envie a solicitação no feed. O feed e suas interações continuam demonstrativos. Não há painel de aprovação ainda. Não use chaves secretas no frontend. O build não foi executado porque o registro npm estava inacessível no ambiente de criação.
