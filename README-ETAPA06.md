# Etapa 06 — Painel do artista
Execute npm install e npm run dev. Abra /painel-artista ou Meu painel no feed.
O usuário precisa estar cadastrado e aprovado no banco. A aprovação administrativa ainda não possui interface; não altere RLS para contornar isso.
O painel grava perfis, publicações e mídias reais. O feed anterior continua demonstrativo. Imagens são públicas; ocultar uma publicação não revoga a URL de uma imagem. Excluir uma publicação não apaga automaticamente seu arquivo de Storage. Links YouTube e Spotify são registrados, não reproduzidos nesta etapa. Categorias do artista e moderação serão integradas depois.
Faça backup antes de sobrepor arquivos. Teste cadastro, aprovação, perfil, upload, publicação, ocultação e exclusão. Não use chaves secretas no frontend.
